# Nintendo Museum Ticket Watch — интерактивный Telegram-бот

Многопользовательский бот. Любой, кто напишет боту, может завести свои даты, и
бот раз в несколько минут проверяет официальный календарь Nintendo Museum и
шлёт уведомление, когда выбранная дата становится доступной.

Работает через открытый JSON-эндпоинт календаря
(`/en/api/calendar?target_year=YYYY&target_month=M`), без браузера и Playwright.

## Команды

| Команда | Что делает |
| --- | --- |
| `/start` | приветствие и список команд |
| `/watch` | добавить дату(ы) для отслеживания |
| `/list` | мои даты и их статус |
| `/status` | статус по моим датам + когда была последняя проверка |
| `/stop` | удалить одну или все даты |
| `/whoami` | узнать свой chat_id |
| `/admin` | сводка по всем пользователям (только для админа) |
| `/help` | подсказка |

Даты: `ГГГГ-ММ-ДД`. Можно списком (`2026-10-10,2026-10-12`) или диапазоном
(`2026-10-10..2026-10-12`).

Статусы дня: **✅ доступно**, **разобрано**, **музей закрыт**, **нет данных**.
Уведомление приходит один раз; если дата снова станет недоступной, бот
перевзведётся и уведомит опять при следующем появлении.

Покупка билетов — вручную на официальном сайте. Бот только уведомляет и не
входит в Nintendo Account.

## Переменные окружения

| Имя | Обязательна | По умолчанию | Описание |
| --- | --- | --- | --- |
| `TELEGRAM_BOT_TOKEN` | да | — | токен бота от @BotFather |
| `CHECK_INTERVAL_MIN` | нет | `10` | как часто проверять, минут |
| `DB_PATH` | нет | `data/nintendo.db` | путь к файлу базы |
| `ADMIN_CHAT_IDS` | нет | — | id админов через запятую (для /admin) |

Можно использовать того же бота, что и раньше, но **у long-polling бота на один
токен должен быть ровно один запущенный экземпляр**. Если у тебя уже крутится
Shimanami-бот на этом токене — заведи для Nintendo **отдельного** бота в
@BotFather (свой токен), иначе Telegram будет отдавать ошибку конфликта.

## Деплой на Railway

1. Залей содержимое папки `bot/` в GitHub-репозиторий.
2. railway.app → New Project → Deploy from GitHub repo → выбери репозиторий.
   Если файлы в подпапке — Settings → Root Directory = `bot`.
3. Variables → добавь `TELEGRAM_BOT_TOKEN` (и при желании `CHECK_INTERVAL_MIN=5`),
   нажми **Apply changes**.
4. Чтобы база переживала передеплой: создай **Volume** с mount path `/data`,
   потом переменную `DB_PATH=/data/nintendo.db` → Apply changes.
5. В Deploy Logs дождись `Bot started. Check interval = ... min.`
6. Напиши боту `/start`.

## Локальный запуск

```bash
cd bot
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
TELEGRAM_BOT_TOKEN=ТОКЕН CHECK_INTERVAL_MIN=5 python bot.py
```

## Ограничения

- JSON-эндпоинт неофициальный: если Nintendo изменит формат/статусы, проверка
  может начать ошибаться — тогда надо будет поправить функцию `classify` в `bot.py`.
- Календарь отдаёт ограниченное окно месяцев. Дату далеко в будущем, которой ещё
  нет в календаре, бот покажет как «нет данных», пока месяц не откроется.
